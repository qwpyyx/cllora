## 1. 已完成实验资产梳理

### 1.1 已完成：Qwen3-14B + GSM8K 主结果

设置：

| Setting | Value |
|---|---:|
| Model | Qwen3-14B-Instruct |
| Dataset | GSM8K |
| Total clients | 50 |
| Clients per round | 10 |
| Global rounds | 5 |
| Local epochs | 10 |
| LoRA rank | 8 |
| Upload target | q_proj, v_proj |
| Partition | quantity / Dirichlet alpha=10 |
| Budget | 12.5% (1760 / 14080) |
| Seeds | 28, 42, 45 |
| FedSP-LoRA config | qv-block + SN-P1/P2 depth_rank + Gram dimension normalization |

主结果：

| Method | s28 | s42 | s45 | Mean | Std | vs Dense | 说明 |
|---:|---:|---:|---:|---:|---:|---:|---|
| Dense | 37.91 | 38.36 | 38.21 | **38.16** | 0.23 | 100% | Full-upload reference |
| FLASC | 36.77 | 36.62 | 37.38 | **36.92** | 0.40 | 96.7% | Global TopK |
| **FedSP-LoRA** | **37.00** | **36.24** | **36.09** | **36.44** | **0.49** | **95.5%** | SN-P1/P2 scheduling |
| ComPEFT | 34.57 | 36.39 | 34.34 | **35.10** | 1.12 | 92.0% | TopK + PQ |
| FLM-TopK | 33.97 | 33.21 | 34.04 | **33.74** | 0.47 | 88.4% | Block opt TopK |
| FedComp | 32.07 | 29.04 | 33.28 | **31.46** | 2.21 | 82.5% | Row-vector compression |

关键结论：

- FedSP-LoRA vs FLM-TopK：+2.70 EM；
- FedSP-LoRA vs FedComp：+4.98 EM；
- FedSP-LoRA vs ComPEFT：+1.34 EM；
- FedSP-LoRA 恢复 Dense 的 95.5%；
- FLASC 在 GSM8K 上略高于 FedSP-LoRA，但这是单一数学任务上的结果，后续 Dolly 显示 FLASC 在生成任务上不稳定。

### 1.2 已完成：Qwen3-14B + Dolly-15K 跨任务结果

设置：Qwen3-14B，Dolly-15K，3 seeds，alpha=0.5 label-skew。

| Method | s28 | s42 | s45 | Mean R-1 | Std | Mean R-L | Gen Len |
|---|---:|---:|---:|---:|---:|---:|---:|
| FedComp | 43.13 | 43.31 | 43.47 | **43.30** | ±0.17 | 34.07 | ~57 |
| FLM-TopK | 42.65 | 42.34 | 43.04 | **42.68** | ±0.35 | 33.96 | ~56 |
| **FedSP-LoRA** | 42.98 | 42.83 | 41.99 | **42.60** | ±0.54 | 33.82 | ~55 |
| Dense | 42.54 | 41.47 | 42.45 | **42.15** | ±0.61 | 34.05 | ~57 |
| ComPEFT | 34.37 | 40.48 | 35.70 | **36.85** | ±3.20 | 28.28 | ~81 |
| FLASC | 27.96 | 28.35 | 28.28 | **28.20** | ±0.20 | 20.22 | **~126** |

关键结论：

- FedSP-LoRA 与 FedComp / FLM-TopK 同属第一梯队；
- FLASC 在 GSM8K 表现强，但在 Dolly 上出现生成崩溃，Gen Len 接近上限；
- ComPEFT 在 Dolly 上不稳定；
- FedSP-LoRA 是当前最适合支撑“跨任务稳定性”的方法之一。

> 注意：论文主表建议使用 **ROUGE-L** 作为 Dolly 主指标，ROUGE-1 和 Gen Len 可作为辅助指标或正文说明。当前需要补齐每个 seed 的 ROUGE-L，便于计算 mean/std。

### 1.4 已完成：初版 ablation

当前已有 Qwen3-14B + GSM8K + seed28 + 12.5%：

| Variant | 配置 | EM | Δ vs Full | 当前判断 |
|---|---|---:|---:|---|
| Full FedSP-LoRA | depth_rank, gap=1.0 | **37.00** | — | 主方法 |
| w/o depth calibration | SN raw | 36.47 | −0.53 | depth calibration 有效 |
| w/o P2 | gap=0.0 | 36.9977 | −0.00 | 当前 setting 下 P2 影响不明显 |
| ab_pair atom | ab_pair | 30.78 | −6.22 | qv-block / structural granularity 很关键 |

当前结论：

- 这组 ablation 已经能证明 depth calibration 和 qv-block 粒度的重要性；
- 但它**不能充分证明 P2 的有效性**，因为 homogeneous GSM8K alpha=10 + 12.5% budget 下 P2 不敏感；
- 最终 ablation 需要换到更能暴露 P2 作用的 setting，例如更强 heterogeneity、低预算或生成任务。

|---|---:|

| FLM-TopK | 37.00 |
| FLASC | 36.62 |

当前判断：

- FedSP-LoRA 超过 FLASC，与 FLM-TopK 持平；

## 8. Phase 5：Figure 3 — P1/P2 ablation

**目标**：证明 FedSP-LoRA 的两个核心调度层次是必要的：

1. P1：module-level quota allocation；
2. P2：client-level assignment。

### 8.1 当前 ablation 的问题

已有 ablation 显示：

- w/o depth calibration：下降 0.53 EM；
- ab_pair atom：下降 6.22 EM；
- w/o P2：几乎不变。

这说明当前 Qwen3 + GSM8K + alpha=10 + 12.5% 的 setting 对 P2 不敏感。因此不能直接用这组结果作为最终 P1/P2 ablation 图。

### 8.2 推荐最终 ablation setting

应选择更容易体现 P2 作用的 setting：

| 候选 setting | 推荐度 | 原因 |
|---|---:|---|
| Qwen3-14B + Dolly label-skew | 高 | 生成任务 + label skew，更容易暴露 client assignment 差异 |
| Qwen3-14B + FinGPT alpha=1 / label-skew | 高 | domain task + non-IID，更适合 P2 |
| Qwen3-14B + GSM8K alpha=1 | 中 | 已有初步结果，但 performance 差异可能仍小 |
| Qwen3-14B + GSM8K 6.25% budget | 中 | 低预算下 assignment 更关键 |

优先推荐：**Qwen3-14B + FinGPT 或 Dolly，12.5% / 6.25%，seed28 起跑**。

### 8.3 Ablation variants

最终图建议用 4 个柱：

| Variant | P1 | P2 | 含义 |
|---|---|---|---|
| AB-Effective | ✗ | ✗ | effective-magnitude local Top-K anchor |
| P1-only | ✓ | ✗ | 有 signal-noise quota，但 client assignment 简化 |
| P2-only | ✗ | ✓ | 使用 uniform / non-adaptive quota，但用 P2 assignment |
| FedSP-LoRA | ✓ | ✓ | 完整方法 |

如果当前代码暂时没有 P2-only，则最低版本使用：

| Variant | 含义 |
|---|---|
| AB-Effective | local magnitude anchor |
| FedSP-LoRA w/o P2 | P1-only |
| FedSP-LoRA w/o depth calibration | no calibrated P1 |
| FedSP-LoRA | full |

但论文上最理想的是 P1-only / P2-only / full 三者都具备。

### 8.4 图的形式

建议用 grouped bar：

- x-axis：Variant；
- y-axis：Relative-to-Dense performance 或任务主指标；
- 两组柱：例如 FinGPT 与 Dolly，或者 12.5% 与 6.25%。

正文要强调：即使 performance 差异不大，也应同时报告 selection overlap / covered modules 作为机制佐证。P2 的作用可能更多体现为降低 redundancy，而不是在某个单 seed 上立即提升 EM。
