# 研究点2-v9：实验结果记录（更新版）

> 本文档用于记录当前 v9 版本方法在已完成实验中的阶段性结果。  
> 本次更新的核心变化是：**raw qv-block upload 不再作为最终主方法，而降级为 ablation；最终主方法调整为 Ours-Enc，即 signal-noise-aware qv-block scheduling + fine-grained encoding。**  
> 当前最新完成结果表明：在 Qwen2.5-14B + GSM8K 上，Ours-Enc 在相同 12.5% uplink budget 下超过 ComPEFT、FedComp，并基本恢复 dense full-upload 性能。

2. 但 **raw Ours** 在 mature baselines 面前不够强，尤其不如 ComPEFT / FedComp / FLM-TopK。

4. 因此，论文最终方法应从“单纯结构化 sparse upload”升级为：  
   **signal-noise-aware scheduling layer + fine-grained encoding layer**。

## 1. 方法版本说明

### 1.1 raw Ours：结构化 qv-block scheduling

早期 v9 主方法为：

```text
qv-block atomic unit
+ depth-balanced calibrated P1
+ plain P2-L / exact max-cost-flow assignment
+ raw selected qv-block upload
```

其作用是验证：

- q/v LoRA block 是比单独 A/B tensor 更合理的上传原子；
- P1/P2 可以让不同 clients 上传互补的 qv-blocks；
- depth-balanced quota 可以避免只选局部极大范数层。

但 raw Ours 的短板是：

```text
每个 qv-block 成本较高；
在 12.5% budget 下，每个 client 只能上传很少 qv-block；
被选中 block 内部仍是 raw upload，没有利用成熟压缩编码。
```

因此，raw Ours 现在应作为 ablation：

```text
Ours w/o encoding
```

### 1.2 Ours-Enc：最终推荐主方法

当前推荐最终主方法为：

```text
Ours-Enc = signal-noise-aware qv-block scheduling + fine-grained encoding
```

具体流程：

```text
Step 1: 用 SN-P1/P2 在 client-qv-block 层面选择候选通信区域；
Step 2: 候选预算设为实际预算的 m 倍，例如 m=3；
Step 3: 在候选 qv-block tensors 内部执行 ComPEFT-style TopK + probabilistic quantization；
Step 4: 实际上传预算仍然保持与 baselines 完全相同。
```

当前效果最好的配置为：

```text
enc_compeft_m3:
  upload_atomic_mode = qv_block
  upload_score_mode = sn_p1p2
  sn_p1_norm_mode = depth_balanced
  sn_depth_group_ratios = 1,1,2
  sn_gap_eta = 0.0
  sn_force_full_budget = True
  sn_encoder_mode = compeft
  sn_candidate_budget_multiplier = 3
  sn_encoder_packet_num = comm_budget
```

该设计的论文定位：

> Ours does not replace fine-grained compression. Instead, it provides a signal-noise-aware scheduling layer that tells the encoder where the limited compressed values should be placed.

### 2.5 Ours-Enc 压缩与调度诊断

Ours-Enc / enc_compeft_m3 的关键记录：

| Item | Value |
|---|---:|
| Encoder | ComPEFT-style TopK + PQ |
| Actual packet budget | 2112 packets/client/round |
| Candidate budget multiplier | 3 |
| Candidate schedule budget | 6336 packets/client/round |
| qv-block unit cost | 352 packets |
| Candidate qv-blocks per client | 18 |
| Candidate tensors per client | 72 |
| Actual mean nonzero | 633600 |
| Actual density within candidate tensors | 26.86% |
| Records | 50 |
| P2 unfilled quota | 0 |

重要说明：

- `6336 packets` 只是候选区域调度预算，不是实际上传预算；
- 实际上传仍然是 `2112 packets/client/round`，与 ComPEFT、FedComp、FLASC 完全对齐；
- Ours-Enc 只是在 SN-P1/P2 选择出的候选区域内做 fine-grained encoding。

与单独 ComPEFT 的对比：

| Method | Mean Nonzero | EM |
|---|---:|---:|
| ComPEFT | ~618146 | 31.8423 |
| Ours-Enc | 633600 | **35.3298** |

解释：

> Ours-Enc 的 nonzero 数量只比 ComPEFT 多约 2.5%，但 EM 高出 3.49。这说明提升主要来自 where-to-encode 的调度，而不是单纯传输了更多参数。

与 FedComp 的对比：

| Method | Mean Nonzero | EM |
|---|---:|---:|
| FedComp | ~771581 | 32.6763 |
| Ours-Enc | 633600 | **35.3298** |

解释：

> Ours-Enc 使用更少 nonzero，却取得更高 EM，说明通信位置选择比单纯增加非零上传量更重要。

### 2.6 Ours-Enc selection overlap

Ours-Enc / enc_compeft_m3 每轮每个 client 选择：

```text
18 qv-blocks = 72 tensors
```

每轮的 union selected tensors 约为：

```text
136 ~ 144 tensors
```

pairwise Jaccard 约为：

```text
0.37 ~ 0.39
```

fully shared tensors 为：

```text
0
```

解释：

- 相比 raw Ours，Ours-Enc 因为 candidate multiplier=3，候选区域更大，所以 overlap 上升是正常的；
- 但 fully shared tensors 仍为 0，说明没有退化成所有 clients 选择同一批层；
- P2 assignment 仍然保留了 client-level complementarity。

Depth 分布为：

| Depth Group | Selection Count |
|---|---:|
| Lower | 225 |
| Middle | 225 |
| Upper | 450 |

这对应 `sn_depth_group_ratios = 1,1,2`，说明 depth-balanced scheduling 正常生效。

### 2.7 Qwen2.5 当前结论

Qwen2.5 当前结果支持以下结论：

1. **Raw Ours 有效但不够强**：它超过 AB baselines，但输给 ComPEFT/FedComp。
2. **成熟压缩 baseline 的强点在 fine-grained encoding**。
3. **Ours-Enc 显著优于单独 ComPEFT/FedComp**，说明 SN scheduling 与 fine-grained encoding 是互补关系。
4. 最终方法应以 Ours-Enc 为主，raw Ours 作为 ablation。

推荐论文句子：

> Ours-Enc achieves 35.33 EM on Qwen2.5-14B with only 12.5% uplink budget, outperforming ComPEFT by 3.49 EM and FedComp by 2.65 EM. Compared with ComPEFT, Ours-Enc transmits a similar number of nonzero values but places them within signal-noise scheduled qv-block regions, demonstrating that where to encode is as important as how to encode.

## 4. 当前结果的论文含义

### 4.1 方法主线调整

原始叙事：

```text
Ours as a standalone sparse upload algorithm.
```

现在应调整为：

```text
Ours-Enc as a scheduling-enhanced fine-grained compression framework.
```

推荐论文表达：

> Existing fine-grained compression methods mainly focus on how to encode sparse LoRA updates under a given budget, but they are agnostic to where the limited compressed values should be placed across clients, layers, and LoRA modules. Ours-Enc addresses this missing scheduling dimension by first identifying signal-noise-favorable qv-block regions through P1/P2 scheduling and then applying fine-grained encoding within the scheduled regions.

中文理解：

> 现有细粒度压缩方法主要解决“如何编码”问题，但忽略“有限的压缩值应该放在哪些 client/layer/module 上”。Ours-Enc 通过 P1/P2 先调度 signal-noise 更有利的 qv-block 区域，再在这些区域内做细粒度编码。

---

### 4.2 当前证据链

当前实验已经形成比较完整的证据链：

#### Evidence 1: qv-block scheduling 有效

Raw Ours 在 Qwen2.5 和 Llama 上均显著超过 AB/magnitude-only baselines。

| Model | Dense | Best AB | Raw Ours | Gain over Best AB |
|---|---:|---:|---:|---:|
| Qwen2.5-14B | 34.4453 | 28.8097 | 30.4523 | +1.6426 |
| Llama-3.1-8B | 17.4627 | 6.4443 | 15.7190 | +9.2747 |

#### Evidence 2: raw upload 不足

在 mature baselines 面前，raw Ours 不是最强：

| Model | Raw Ours | Strong Mature Baseline | Observation |
|---|---:|---:|---|
| Qwen2.5-14B seed42 | 29.9469 | FedComp 32.6763 / ComPEFT 31.8423 | raw Ours loses to fine-grained encoding |
| Llama-3.1-8B | 15.7190 | FLM-TopK 17.9429 / ComPEFT 16.1486 | raw Ours loses or is close |

#### Evidence 3: scheduling + encoding 互补

在 Qwen2.5 seed42 上：

| Method | EM |
|---|---:|
| ComPEFT | 31.8423 |
| FedComp | 32.6763 |
| Raw Ours | 29.9469 |
| **Ours-Enc** | **35.3298** |

结论：

> Fine-grained encoding is necessary, but scheduling further determines whether the encoded values are useful.

## 5. 当前不足与风险

### 5.1 Ours-Enc 目前只有 Qwen2.5 seed42

当前 Ours-Enc 最强结果来自单 seed：

```text
Qwen2.5-14B + GSM8K + seed42
```

因此现在不能写成最终定论：

```text
Ours-Enc always outperforms all baselines.
```

更稳妥的说法是：

```text
The initial Qwen2.5 result demonstrates that signal-noise scheduling is complementary to fine-grained encoding and can substantially improve ComPEFT under the same packet budget.
```

### 5.2 需要补 m2/m4 和多 seed

当前 m3 最好，但还需要验证：

- m2：候选区域较小；
- m4：候选区域较大；
- seed28 / seed45：多 seed 稳定性。

当前 overnight 正在跑这些结果，后续应补入本文档。

### 5.3 FLM-TopK 太慢

FLM-TopK 在 Llama 上表现很强，但在 Qwen2.5 上速度非常慢。当前实现已加入 fast/capped 版本：

```text
flm_opt_max_iter = 40
flm_max_blocks = 256
```

但需要在实验表中明确标注为：

```text
FLM-TopK-fast / capped FLM-TopK
```

避免和原始 full block optimization 混淆。

### 5.4 Dense 不是理论 upper bound

在 Llama 上 FLM-TopK 超过 Dense，在 Qwen2.5 上 Ours-Enc 略高于 Dense。这不一定是错误，因为压缩可能带来正则化效果。论文中应表述为：

```text
Dense full upload is a full-communication reference rather than a theoretical accuracy upper bound.
```

## 7. 当前阶段结论

当前阶段可以形成如下结论：

1. **Raw Ours 证明了 signal-noise-aware qv-block scheduling 的有效性**：它在 Qwen2.5 与 Llama 上均超过 AB/magnitude-only baselines。
2. **Raw Ours 不能作为最终主方法**：mature fine-grained compression baselines 在 Qwen2.5/Llama 上表现更强。
3. **Ours-Enc 是当前最有希望的最终方法**：在 Qwen2.5 seed42 上，它以 12.5% budget 达到 35.3298 EM，超过 ComPEFT、FedComp，并基本恢复 Dense 性能。
4. **论文贡献应重新定位为 scheduling-enhanced compression**：现有方法解决 how to encode，Ours-Enc 补充 where to encode。
5. 接下来最重要的是补齐 Qwen2.5 Ours-Enc 多 seed / ablation，并在 Llama-3.1 上复现 Ours-Enc 的提升。

## 8. 可直接用于论文的阶段性表述

### English version

> The raw qv-block scheduling variant validates the effectiveness of signal-noise-aware assignment: it consistently improves over AB-Factor and AB-Effective on both Qwen2.5-14B and Llama-3.1-8B. However, mature fine-grained compression baselines reveal that raw block upload is not sufficiently communication-efficient. We therefore extend the method into Ours-Enc, which first schedules signal-noise-favorable qv-block regions and then applies fine-grained TopK+PQ encoding within the scheduled regions. On Qwen2.5-14B/GSM8K, Ours-Enc achieves 35.33 EM with only 12.5% uplink budget, outperforming ComPEFT by 3.49 EM and FedComp by 2.65 EM under the same packet budget.

### 中文解释

> raw qv-block 调度版本证明了 signal-noise-aware assignment 的有效性：它在 Qwen2.5-14B 和 Llama-3.1-8B 上都稳定优于 AB-Factor / AB-Effective。然而，成熟细粒度压缩 baseline 表明，单纯 raw block upload 的通信效率仍然不足。因此，我们将方法扩展为 Ours-Enc：先调度 signal-noise 更有利的 qv-block 区域，再在这些区域内执行 TopK+PQ 细粒度编码。在 Qwen2.5-14B/GSM8K 上，Ours-Enc 仅使用 12.5% uplink budget 就达到 35.33 EM，在相同 packet budget 下分别超过 ComPEFT 3.49 EM、超过 FedComp 2.65 EM。
